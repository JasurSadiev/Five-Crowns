The app could not start

The page loaded but the application never mounted. This is almost always a configuration problem rather than a bug in the game.

  • Open the browser console - the first red error names the cause.
  • Check that the site was built with your real Firebase values (VITE_FIREBASE_*) and not with VITE_USE_EMULATORS=true.
  • Remember that .env.local overrides .env during vite build.
